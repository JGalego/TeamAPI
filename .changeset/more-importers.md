Four more `teamapi import` sources beyond `github-org`: `backstage` (a catalog file or the catalog API), `okta` (directory groups, also usable for Entra via `importDirectoryGroups`), `slack` (channels as team skeletons) and `csv` (an HRIS export — the only source that can populate `roles[]`).
