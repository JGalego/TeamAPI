TeamAPI

Every team has an API.

Time to bring yours online.

$ npm install -g @jgalego/teamapi

Ask it something


    

  


  
Quick start

  

    

      
Write it down

      
One file per team: what it owns, who's accountable, how much it can take on.

      
$ teamapi scaffold cart \
    --type stream-aligned \
    --out teams/cart.yml

    

    

      
Serve the API

      
Your whole org over HTTP, and a dashboard to browse it.

      
$ teamapi serve-api ./org
# localhost:3000/dashboard

    

    

      
Let agents in

      
Point an assistant at the MCP server and ask in plain English.

      
$ teamapi serve-mcp ./org
# "who owns checkout-api?"
