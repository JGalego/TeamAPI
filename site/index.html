TeamAPI

Who owns this? Just curl your org.

One teamapi.yml per team, reviewed in pull requests. Out comes a REST API, diagrams, and an MCP server your assistant can query.

$ npm install -g @jgalego/teamapi 

    

    

  


  
Three steps

  

    

      01
      Write it down
      
One file per team: what it owns, who's accountable, how much it can take on.

      
teamapi scaffold my-team \
  --type stream-aligned \
  --out teamapi.yml

    

    

      02
      Serve it
      
A read-only REST API plus a dashboard, straight from the files. No database.

      
teamapi serve-api ./org
# → localhost:3000/dashboard

    

    

      03
      Ask it anything
      
Point Claude at the MCP server and ask in plain English.

      
teamapi serve-mcp ./org
# "which team is overloaded?"
